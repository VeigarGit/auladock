# Como rodar o projeto:
1- Usar git clone para clonar o repositório com a mesma organização existente;
2- Ter instalado os requeriments especificados, como python e docker;
3- Utilizar o comando sudo docker-compose up --build para subir os containers, uso o sudo pois não criei um usuário pro docker;
4- Abrir a aplicação pelo terminal ou pelo navegador, mediante os links que serão fornecidos;
5- Caso queira ver a tabela do database, use: sudo docker exec -it mysql_final mysql -uuser_app -papppassword -e "SELECT * FROM app_db.usuarios;" .
